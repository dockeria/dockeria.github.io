Color Chart

This is a chart of the 216 colors that will show on any color setting with any graphical browser. Using these colors will assure you that your viewers will see that same colors that you want them to.

This chart can display either the hexadecimal number or the decimal number for the color. Make sure you have the radio button corresponding to the number system you want is checked and the click on the color you would like. The value will appear in the three text fields below. When hexadecimal is selected, then the number that is given is ready for you to just copy and paste into your HTML code. If you change the radio buttons, then the value found in the text fields will be converted to the new selection.
